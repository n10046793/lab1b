Project Name: Delivery Calculator
The user is promoted to enter a purchase amount. Based on the purchase amount a delivery fee is generated. Then the user choses which day they want the delivery. Delivery fees can be $5, $3, $1, or free depending on purchase value. Any day of the week can be chosen as a delivery day. If the user enters a purchase value of zero or less, the user is promoted to enter a positive value.
Example: A purchase of $100 would trigger a message of fee delivery.
Setup using standard python library with Visual Studio Code
Limitations: for the days of the week, only lowercase letters are accepted, if the first letter of the day is capitalized the program will give an error
